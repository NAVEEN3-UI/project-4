# Expense Tracker Application (React-style frontend + Express + MongoDB)

Track income and expenses, categorize transactions, and see totals. The starter UI uses vanilla JavaScript to keep it simple to run; migrate it to React as an extension if required by your reviewer.

## Setup
1. Start MongoDB locally or create an Atlas database.
2. Copy `.env.example` to `.env` and configure `MONGODB_URI`.
3. Run `npm install` and `npm start`.
4. Open http://localhost:3000.

This is a learning starter, not financial advice. Never commit `.env` or database credentials.
